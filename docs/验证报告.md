# 隔离验证报告

验收对象是仓库的开发版和用源码打包的 Lumen.app。产品设计稿使用示例数据，当前测试实际调用 Swift 客户端和 Python 文件引擎。

## 环境与操作边界

本地开发验收使用 Apple Silicon、macOS 14.1.2、Xcode 15.4、Swift 5.10 和系统 Python 3.9.6。引擎和 Swift 联调测试分别创建新的临时目录和状态库。应用使用演练专属废纸篓。文件操作回归使用 macOS sandbox-exec，禁止网络及临时工作区外的写入，并在测试开头检验保护规则。没有对真实用户 Library、Downloads、用户废纸篓或已安装的应用执行清理，也未安装后台作业。

## 已验证场景

| 范围 | 实际检查 |
| --- | --- |
| 扫描 | 快速/深度覆盖、显式保护根、权限错误、别名、硬链接、同大小不同内容、哈希重用和失效 |
| 应用与工程 | bundle 归属、多副本歧义、Codex/Claude 会话、跨项目素材、Git 跟踪、模型共享与 HTML/Vite/FCPXML 引用 |
| 授权与任务 | 扫描被撤回、同路径换根、过期预演、重复收尾事件、已登记输入保护、演练返回原有工作区 |
| 写操作 | 在接口端再次扫描、拒绝整个重复组被移走、符号链接/硬链接/已占用保护、模拟镜像挂载与卷离线 |
| 隔离与恢复 | 并发操作、中断恢复、同名冲突、旁置恢复、重复恢复以及单独清空 |
| 卸载与废纸篓 | 合成应用及签名不符的拒绝、保留目录阻止整包操作、已验证残留、选定废纸篓条目范围 |
| 原生联调 | 由 Swift Store 发起真实子进程请求，创建演练、扫描、隔离、恢复、撤回、退出；共享硬链接的分区去重及排序 |

最新本机标准套件运行了 50 项，49 项通过，1 项可选实包用例跳过。其中包括浏览器凭据、书签、会话及离线资料保留，共享容器计量，以及清理规则不适用时仍保留已知工程引用。另一次显式提供微软归档的运行中，当时的 45 项用例全部通过。

### 官方应用包实测

从微软官方更新端点取得 VS Code 1.95.3 ARM64 归档，在临时目录展开。核对 Microsoft Team ID、bundle ID 和代码签名后对该副本执行卸载隔离，再原位恢复并重新检查元数据清单和签名。归档 SHA-256 为 `fe01f564777afb75703e748ada00f1204f0495be54947d6ffb513e5a5eb16a08`，大小 135,066,855 B。归档与展开的第三方应用未纳入本仓库。本用例没有启动 VS Code。[微软固定版本入口](https://update.code.visualstudio.com/1.95.3/darwin-arm64/stable)

### 原生窗口与磁盘扫描基线

GitHub 托管 macOS 15 的辅助功能测试启动打包好的 Lumen.app，读取实际窗口标题，从空工作区点击「创建演练样本」，核对授权目录，触发重扫并验证扫描标识改变，最后返回原工作区并核实授权仍为空。[首次原生窗口验收日志](https://github.com/Moosphan/lumen/actions/runs/45357685971)

在上述本机环境中用 `./scripts/test-isolated.sh --benchmark` 生成 100 个临时目录，每个目录包含 100 份各自独立的 64 B 文件，同一内容重复出现在不同目录中。扫描器单次测量结果如下。

| 模式 | 索引文件数 | 耗时 | 内容哈希读取 | 哈希复用 | 进程累计峰值内存 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 快速盘点 | 10,000 | 0.99 s | 0 | 0 | 40.5 MiB |
| 首次深度盘点 | 10,000 | 2.15 s | 10,000 | 0 | 47.6 MiB |
| 同目录深度重扫 | 10,000 | 2.15 s | 0 | 10,000 | 55.1 MiB |

此测量只涵盖扫描引擎，未计入 UI 绘制与结果持久化。重扫复用了全部哈希，同时仍逐项检查文件身份。大媒体、多卷、百万文件规模需要各自的测量。

## 复现与证据边界

```bash
./scripts/test-isolated.sh
./tests/native/smoke.sh
/usr/bin/python3 scripts/package.py
codesign --verify --strict dist/Lumen.app
```

隔离测试不要求下载真实应用包。可另行准备上述官方归档后，依照 tests/test_macmanage.py 的可选用例进行实包验证。仓库 CI 的每次运行可查看各测试命名、用例数、跳过原因和打包结果。[GitHub Actions](https://github.com/Moosphan/lumen/actions)

待发布验收包括真实账号登录态、物理外接盘拔插、系统权限弹窗、更多原生界面流程，以及大媒体和百万文件规模下的端到端性能。当前包采用本机开发签名，正式发行仍需 Developer ID 签名与公证。
